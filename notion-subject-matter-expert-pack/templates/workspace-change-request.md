# Workspace change request (Level 2)

Use this form to ask for approval of a consequential Notion change. Approval covers exactly what is written here; anything wider needs a new request.

| Field | Entry |
|---|---|
| Action | (replace, delete, archive, move, schema change, automation, sharing change, publication, notification, integration connection, export) |
| Targets | (pages, databases or teamspaces, with URLs) |
| Content or properties affected | |
| Who will see the result | |
| Who will be notified | (mentions, assignments, automations, followers) |
| Permission effect | (for moves: old parent and new parent; for sharing: who gains or loses access) |
| Dependents affected | (relations, rollups, formulas, views, automations, integrations, links) |
| Undo path | (page history, Trash, duplicate or export taken first, reverse move) |
| Reason | |
| Reviewed by | (notion-governance-reviewer findings, or "not independently reviewed") |

Decision: approved / approved with changes / declined. Declined means the change is not attempted another way.
