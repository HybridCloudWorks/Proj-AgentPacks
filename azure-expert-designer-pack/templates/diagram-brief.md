# Diagram brief

Fill this in before drawing. It records what the agent's operating contract asks for first: purpose, audience, scope, source of truth, fidelity, output format and task type. A field left blank becomes a recorded assumption, not a silent default.

| Field | Value |
|---|---|
| Diagram title | |
| Task type | design, reconstruction, review or export (one) |
| Purpose | the decision or conversation the diagram supports |
| Audience | who reads it, and what they already know |
| Scope | workload, environment, tenants, subscriptions and regions in scope |
| Out of scope | what is deliberately not drawn |
| Source of truth | requirements document, infrastructure paths and commit, existing diagram, or none |
| Fidelity | context, logical, network detail or deployment detail |
| Output format | `.drawio` (default); export formats only when the deliverable needs them |
| Output location | path, and whether it is a new file or an approved overwrite |
| Views | one row per page: page name and what it shows |
| Consumption size | slide, wiki page width or print size |
| Live evidence | none, or the read-only check the user approved and who approved it |
