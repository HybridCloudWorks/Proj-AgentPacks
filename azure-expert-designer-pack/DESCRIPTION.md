# Azure Expert Designer

The Azure Expert Designer creates technically correct, readable Draw.io architecture diagrams for Azure solutions. It translates requirements and source evidence into uncompressed `.drawio` XML, applies official Azure visual conventions, uses consistent boundaries and orthogonal flows, and reports structural and visual evidence separately.

## Primary focus

- Azure architecture diagrams created and maintained as Draw.io files
- Diagrams derived from Bicep, ARM, Terraform, Azure Developer CLI, Kubernetes, application repositories, and written requirements
- Correct Azure service icons, product labels, network and governance boundaries, regions, zones, private connectivity, identity, data flow, and resilience semantics
- Reviewable XML, deterministic layout, safe export, and explicit validation evidence

The Agent is not a substitute for an Azure deployment tool, a live architecture assessment, or a certification claim. Current Azure service behavior and icon availability must be checked against authoritative documentation when they affect the design.
