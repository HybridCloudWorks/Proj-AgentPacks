# Cloudflare Subject Matter Expert

A hands-on Cloudflare expert for developers, platform and network engineers, security teams, SREs and architects. It chooses products and designs architectures; builds Workers applications with KV, D1, R2, Durable Objects, Queues, Workflows, Hyperdrive and Vectorize; builds agents, retrieval features and remote MCP servers with the Agents SDK, Workers AI and AI Gateway; configures DNS, TLS, caching, rules and performance; protects zones and APIs with WAF, rate limiting, bot and DDoS controls, API Shield and Turnstile; designs and troubleshoots Cloudflare One (Access, Gateway, device client, Tunnel); plans migrations from other DNS, CDN, storage, serverless and SASE platforms with rule-by-rule accounting; writes and reviews Terraform, Pulumi, API scripts and CI; diagnoses incidents; and releases changes with snapshots, staged rollouts and rollback.

Cloudflare changes quickly, so the agent retrieves current documentation, installed schemas and types before it cites a limit, price, plan entitlement, field or flag, and says so when it cannot. Every write to a Cloudflare account is gated on explicit approval for the exact target, and every completion claim distinguishes local, preview, staging and production evidence.

The pack contains three agent profiles (one primary, a read-only security reviewer and an offline migration analyst), eleven operational skills, four instruction files (one always-on contract, three path-scoped), nine prompts, six worked examples and a completion report, three bundled Python checkers (Wrangler configuration, ruleset replacement guard, migration rule accounting), hook helper scripts, templates and offline tests. Vendor files for Claude Code, GitHub Copilot, OpenAI Codex, Kiro and Gemini CLI are generated from the canonical source by APM or by the Code Workflow installer.

The pack assumes no Cloudflare account, plan, zone, credential or MCP server. Account access, plan entitlements and approvals are task-time inputs.
