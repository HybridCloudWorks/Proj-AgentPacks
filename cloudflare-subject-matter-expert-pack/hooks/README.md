# Cloudflare Subject Matter Expert hooks

Nothing in this folder is installed as a native hook. APM copies hook commands verbatim and does not deploy the scripts they call, so any command path shipped in a pack would break after install. Hook wiring belongs to the installer: the Code Workflow installer points hooks at its own copy of the pack, or you wire the reviewed sample yourself.

| Hook or helper | Kind | Purpose and activation | Inputs and dependencies | Behavior and output | Failure handling and guardrails |
|---|---|---|---|---|---|
| `sessionStart` via `tooling/hook_runner.py` | Native-hook candidate (sample in `samples/`) | When a session starts in a folder with a Wrangler configuration or Cloudflare Terraform code, give the agent a short, safe summary | Host JSON on stdin with `cwd` and `sessionId`; Python 3.11+; the Wrangler checker shipped inside the cloudflare-workers-development skill | Parses configuration without running project code; returns `additionalContext` with the config file name, compatibility date, finding codes and counts, binding counts and Terraform provider presence; returns `{}` in folders with no Cloudflare configuration | Invalid input returns a fixed error JSON and exit 1 without echoing stdin. Binding names, variable names and other repository-controlled text are never passed to the model |
| `agentStop` via `tooling/hook_runner.py` | Native-hook candidate (sample in `samples/`) | When the primary agent stops, check an optional completion report the user asked for | Host JSON on stdin; optional `.cloudflare-sme/completion.json` in the workspace; `tooling/completion_contract.py` | Validates statuses, criteria, checks with environment labels, account-change rules and the session binding; blocks once with the contract errors | When `stop_hook_active` is true the hook allows the stop and reports the work as unverified, so it cannot loop. A missing report never blocks |
| `pre-cloudflare-work.sh` / `.ps1` | Portable manual helper | Run the same preflight by hand on a project folder | Folder path (default: current folder); Python 3.11+ | Prints the preflight JSON | Read-only; no network, no credentials |
| `post-cloudflare-work.sh` / `.ps1` | Portable manual helper | Validate a completion report by hand | Path to the report JSON; Python 3.11+ | Prints `{"valid": ..., "errors": [...]}`; exit 0 valid, 1 invalid | Reads only the given file; error messages never include report values |

The completion report is a local evidence index, not proof. It must carry the current `session_id` so a stale report from an earlier run cannot satisfy the check, and it must not contain credentials; the validator rejects text that looks like a token or secret assignment. Review command output and approvals independently.

The sample targets GitHub Copilot's hook file format. It has been reviewed but not exercised in a live Copilot session. Claude Code, Codex, Kiro and Gemini CLI use their own hook files and event names; the installer translates them.
