# Cloud Documentation Archivist

The Cloud Documentation Archivist is a repository-neutral documentation expert for cloud architecture, infrastructure, software delivery, operations, research, decisions, knowledge bases, templates, and docs-as-code publishing.

It explains why documentation exists, selects the correct content type, creates durable and truthful documents, preserves source traceability, validates examples and links, protects sensitive information, and keeps ownership and freshness visible.

The pack uses a thin routing Agent and 18 focused Skills, a reusable template library, safe local hooks and tools, and vendor files generated at install time. It does not assume a specific repository, static-site generator, wiki, Notion workspace, or publishing connector.
