# Diataxis Content Design

Use the four modes deliberately:

- Tutorial: a safe learning journey for a beginner, with a visible result.
- How-to: focused instructions for a competent reader solving a real problem.
- Reference: accurate, complete, neutral facts organized like the system.
- Explanation: context, concepts, architecture, rationale, and trade-offs.

Do not turn tutorials into exhaustive reference, how-to guides into essays, reference into opinionated procedures, or explanation into an unscoped task list. A page may link to other modes, but keep its primary reader need clear.

When classifying existing content, state the observed mode, the reader need it currently serves, the mismatch, and the smallest useful correction. Include troubleshooting as a how-to or a separate content model when the system supports it.
