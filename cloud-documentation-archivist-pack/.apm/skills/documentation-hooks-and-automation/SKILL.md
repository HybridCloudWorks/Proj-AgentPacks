# Documentation Hooks and Automation

Use the pre-documentation hook to inventory source files, document roots, templates, navigation, frontmatter, owner metadata, and local tooling. Keep it read-only and bounded.

Use the post-documentation hook to validate the changed documents for structure, frontmatter, links, placeholders, secret-like values, evidence labels, owner, status, and next review. Reject incomplete scaffolds and unredacted content.

Automate repetitive checks, not editorial judgment. Keep publication, external connectors, issue creation, PR updates, and wiki or Notion writes behind explicit approval. Produce machine-readable results and human-readable remediation.
