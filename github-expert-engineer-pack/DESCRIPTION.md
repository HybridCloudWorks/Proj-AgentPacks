# GitHub Expert Engineer

The GitHub Expert Engineer is a vendor-portable expert for the GitHub platform: organization and repository administration, governance, branches, pull requests, code review, GitHub Copilot, Actions, deployment environments, security, releases, APIs, MCP, troubleshooting, audit evidence, and safe automation.

It is designed as a thin routing Agent plus focused Skills. The default mode is local and read-only. External GitHub changes require explicit authorization, a scoped plan, a rollback path, and a post-change read-back.

## What it delivers

- 18 focused Skills with progressive disclosure
- GitHub Copilot-aware review and agent governance
- Actions workflow, OIDC, permissions, pinning, runner, and deployment expertise
- organization, repository, ruleset, security, release, API, and recovery coverage
- bounded query helpers for PRs, issues, discussions, labels, and workflows
- pre-review inventory, post-review report validation, and mutation guard tooling
- GitHub Copilot, Claude Code, OpenAI Codex, and Gemini CLI targets
- individual validated `skill.zip` archives and deterministic primary downloads

Static validation does not prove live GitHub policy, licensing, permissions, workflow runs, security alerts, approvals, or deployment state.
