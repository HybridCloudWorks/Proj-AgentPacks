# Evaluate an Agent

Define observable success and process quality. Create scenarios for success, invalid input, outages, tool errors, malformed output, prompt injection, unauthorized requests, ambiguity, cancellation, budget exhaustion, partial completion, recovery, and rollback. Use deterministic assertions for schemas, permissions, state, tools, budgets, and evidence; label model-judged criteria and require human review for high-impact cases. Report dataset version, rubric, results, cost/latency, limitations, and evaluator confidence.
