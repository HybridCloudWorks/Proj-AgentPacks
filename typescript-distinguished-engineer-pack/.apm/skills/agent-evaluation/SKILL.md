# Agent Evaluation

Define observable success and process quality. Include successful cases, invalid input, outages, tool errors, malformed responses, prompt injection, unauthorized requests, ambiguity, cancellation, budget exhaustion, partial completion, recovery, and rollback.

Use deterministic assertions for schema, permissions, state transitions, tool arguments, budgets, and required evidence. Label model-judged criteria. Evaluate task outcome, tool choice, grounding and provenance, policy compliance, security boundary enforcement, efficiency, latency, cost, and repeated-run consistency. Require human review for high-impact or ambiguous outcomes.

Keep fixtures safe and reproducible. Report dataset version, rubric, commands, results, limitations, and the difference between a failed task and a failed evaluator.
