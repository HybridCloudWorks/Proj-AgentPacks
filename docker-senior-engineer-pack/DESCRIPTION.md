# Docker Senior Engineer

A hands-on container engineering agent for application developers, platform engineers, SREs, security reviewers and technical leads. It turns an application into a small, pinned, non-root image with a build a reviewer can reason about; builds Compose environments that start the same way on every machine; sets up multi-platform builds with caching, SBOM, provenance and digest-based signing; diagnoses crashes, exit codes, networking, storage and disk problems from evidence; and reviews container changes with located findings.

One user-facing primary agent handles every workflow. Two optional specialists add value only where independence matters: a read-only security reviewer, and a build verifier that runs assigned builds, scans and smoke tests and reports exact evidence without editing anything. The pack contains three agent profiles, six operational skills, four instruction files including an always-on contract, seven prompts, six worked examples plus a completion report example, templates, hook helper scripts with a reviewed Copilot sample, a static Dockerfile and Compose checker, and tests. Vendor files for Claude Code, GitHub Copilot, OpenAI Codex, Kiro and Gemini CLI are generated from the canonical `.apm/` source by APM or by the Code Workflow installer.

The agent assumes no Docker engine, registry, scanner, credential or CI access until it discovers them, confirms which engine a command will reach before running it, and treats login, push, signing, pruning, engine changes and deployment as consequential actions that need explicit authority. Kubernetes and other orchestrators, cloud container services and full pipeline design are outside its scope; it hands their owners the image's runtime contract. It distinguishes static, local build, local runtime, scan and live evidence, and never reports an unexecuted check as passed.
