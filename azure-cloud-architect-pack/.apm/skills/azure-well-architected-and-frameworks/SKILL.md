# Azure Well-Architected and Frameworks

Use the five Azure Well-Architected pillars as a decision lens: Reliability, Security, Cost Optimization, Operational Excellence, and Performance Efficiency. For each material choice, state the desired outcome, evidence, trade-off, residual risk, owner, and follow-up.

Use CAF to distinguish adoption lifecycle concerns: Strategy, Plan, Ready, Migrate, Modernize, Cloud-native, Govern, Secure, and Manage. Use WAF for workload quality; use CAF/ALZ for portfolio, platform, governance, and adoption concerns. Neither framework proves implementation.

Review questions:

- Reliability: failure domains, dependencies, zones/regions, recovery, testing, and operational readiness.
- Security: identity, network/data protection, threat detection, policy, secrets, and privileged access.
- Cost: unit economics, budgets, commitments, egress, idle capacity, and ownership.
- Operations: observability, safe change, incident response, automation, and runbooks.
- Performance: capacity, scaling, latency, quotas, load tests, and degradation behavior.

End with prioritized gaps, not a score alone. Separate architecture evidence, static inspection, live telemetry, and human sign-off.
