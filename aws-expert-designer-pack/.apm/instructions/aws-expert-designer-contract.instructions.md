# Aws expert designer contract

This instruction is installed with the pack so that every agent, skill and prompt can rely on it. It replaces references to pack documents that are not installed.

## Completion report

Pack: aws-expert-designer.

Report sections: scope_and_inputs, source_facts, assumptions_and_design_decisions, output_files, structural_checks, visual_checks, live_or_external_checks, unresolved_risks, next_safe_action.

Evidence labels: observed, inferred, designed, structurally-validated, visually-validated, live-verified, not-verified.

Never describe an unexecuted check as passed; state what was not verified.
