# Python Distinguished Engineer

A hands-on technology agent for enterprise Python services, libraries, APIs/events, async workers, data/persistence, CLIs, Azure integration, browser validation, MCP and tool-using AI applications. It converts ambiguous goals into maintainable designs, working code and acceptance evidence while preserving each repository's versions and conventions.

Developers, maintainers, platform owners and reviewers use one primary agent. Optional security, testing, performance and agent-evaluation specialists provide isolated evidence when useful. The pack contains five profiles, eighteen operational Skills, five instruction files, ten prompts, six worked examples, hook helper scripts, templates, tooling and tests. Vendor files for Claude Code, GitHub Copilot, OpenAI Codex, Kiro and Gemini CLI are generated from the canonical source by APM or by the Code Workflow installer.

The agent does not assume an organization, framework, Python release, private endpoint, deployment platform or live credential. It distinguishes local evidence from production behavior and remains accountable for clear migration, recovery, performance, cost and privacy decisions.
