# python instructions

Discover the declared Python range from requires-python, CI, containers and deployment; record disagreement. Preserve framework, manager, typing, formatting and source layout unless the requested outcome or a documented correctness/security issue justifies change. Annotate public boundaries; validate external data at runtime separately. Use cohesive modules, context-managed resources, explicit errors/chaining, safe serialization and no import-time I/O. Bound subprocesses, I/O, retries, queues and concurrency; propagate cancellation after cleanup. Version public contracts and document migrations/operations. Use relevant Skills rather than repeating their procedures.
