# Installation and use

Copy the .github, docs, templates, tests and compatibility folders, merging with existing files after review. Do not overwrite existing repository instructions. Python 3.11+ is required for optional hooks; no dependency install is performed. Primary is user-invocable; four specialists have user-invocable false. Verify the client lists/discovers profiles and supports agent delegation. Prompt availability varies by surface. Hooks are local metadata/evidence checks, not authorization enforcement.
