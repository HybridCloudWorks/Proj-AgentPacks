# Worked example — user-controlled export URL

Request: review a Python export integration; no implementation or remote posting requested. Primary resolves the diff and gives the security specialist the HTTP adapter, callers, URL origin, credential injection and configured tests. Read/search tools only.

Hypothesis: a user URL reaches an internal network with workload credentials. Trace actual allowlist, redirect handling, DNS/IP behavior, proxy and header propagation before declaring SSRF or leakage. A vulnerable sink alone is not proof of exploitability.

A substantiated High finding includes the exact changed location, demonstrated attacker-controlled path, missing trust check, internal data exposure, recommended approved-endpoint allowlist and redirect/credential boundary, plus negative tests. No real internal endpoint is probed. If network controls cannot be inspected, label that evidence gap.

Primary reconciles with repository policy and acceptance criteria, implements only if requested, and runs approved isolated tests. Report remaining uncertainty, residual risk and whether the finding blocks readiness; do not silently post a GitHub review.
