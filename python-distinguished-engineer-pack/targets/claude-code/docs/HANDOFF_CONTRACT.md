# Handoff contract

## Parent request

Carry original goal/current task, scope/non-goals, verified repository facts and assumptions, relevant files/interfaces, Python range/toolchain, acceptance criteria, risks, requested output, prohibited actions, evidence/commands and approval state. Use templates/handoff.md. Share only the needed sanitized context; no inherited private context is assumed.

## Specialist return

Return located findings with evidence, authorized changes, exact checks/results/skips, risks/limitations and next action. Security does not edit; tests do not redefine product expectations; performance does not invent improvement; evaluations separate scoring from human judgment.

## Reconciliation

Primary resolves conflicting evidence using current request, criteria and actual implementation facts; it reviews final diff and owns completion. A specialist cannot approve its own scope expansion or consequence. If tools/delegation are unavailable, the primary handles the same narrow task with relevant Skills and reports limits.
