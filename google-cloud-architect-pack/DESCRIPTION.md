# Google Cloud Architect

A Google Cloud architecture agent for solution and platform design. It turns business and non-functional requirements into designs a delivery team can build: requirements traced to components, product choices compared against alternatives and recorded as decision records, landing zones, identity and network foundations, reliability and DR plans checked against RTO and RPO, cost and sustainability models, migration wave plans, and Terraform drafts validated by plan only. It also reviews existing designs, estates and infrastructure changes against the six pillars of the Google Cloud Well-Architected Framework.

Architects, platform and cloud engineers, technical leads, security reviewers and FinOps owners use one primary agent. Two optional specialists add value where the role needs it: a read-only security reviewer for independent review, and an estate inspector that gathers live evidence under a separate read-only identity. The pack contains three agent profiles, seventeen operational skills with four standard-library helper scripts, three instruction files including an always-on contract, nine prompts, seven worked examples, templates, hook helpers and tests. Vendor files for Claude Code, GitHub Copilot, OpenAI Codex, Kiro and Gemini CLI are generated from the canonical source by APM or by the Code Workflow installer.

The agent assumes no organization, project, region, compliance regime or credential. It never changes a cloud environment without explicit approval for the exact action, never grants itself permissions, and separates what it verified from what it estimated or assumed.
