# Hypervelocity engineer contract

This instruction is installed with the pack so that every agent, skill and prompt can rely on it. It replaces references to pack documents that are not installed.

## Completion report

Pack: hypervelocity-engineer.

Required sections: objective, scope-and-authorization, actions-and-changed-files, evidence, validation, risks-and-limitations, next-safe-action.

Rules: distinguish observed evidence from inference and unavailable live proof, never claim a live workflow result from static compilation alone, report permissions, safe outputs, secrets, network, and approval boundaries, ask before external writes, permission changes, merges, releases, or production impact.

Never describe an unexecuted check as passed; state what was not verified.
