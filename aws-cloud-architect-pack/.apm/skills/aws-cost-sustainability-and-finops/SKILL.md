# AWS Cost, Sustainability, and FinOps

Use this Skill when selecting Regions/services, reviewing architecture economics, analyzing spend, optimizing resources, planning commitments, or addressing sustainability.

## Cost model

Identify cost dimensions: compute duration/capacity, storage class and requests, data transfer, NAT/endpoints, load balancing, observability, licensing, support, backup, replication, and operations. Model current, expected, peak, and failure scenarios; state assumptions and currency/time window. Use current AWS Pricing API, AWS Pricing MCP, Cost Explorer, CUR, or official pricing pages when available.

Make ownership explicit with account, application, environment, owner, cost center, and data-classification tags. Use budgets, anomaly detection, chargeback/showback, quotas, and review cadence. Do not optimize by weakening security, resilience, recovery, or operability without recording the trade-off.

## Sustainability

Align capacity with demand, choose efficient managed services and storage lifecycles, reduce idle assets, consider Region and workload placement, and measure productive output. Sustainability recommendations must be workload-specific and evidence-aware.
