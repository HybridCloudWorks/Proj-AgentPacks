# Framework Routing

Use Well-Architected for workload design and operation decisions. Use CAF for organizational readiness, transformation planning, operating model, platform capability, and migration workstreams. Use both when a program must connect workload architecture to enterprise adoption.

Six Well-Architected pillars: Operational Excellence, Security, Reliability, Performance Efficiency, Cost Optimization, Sustainability.

Six CAF perspectives: Business, People, Governance, Platform, Security, Operations.

Framework content is version-sensitive. Read the current official source before quoting question IDs, lenses, best practices, or tool behavior.
