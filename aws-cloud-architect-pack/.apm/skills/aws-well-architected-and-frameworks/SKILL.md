# AWS Well-Architected and CAF

Use this Skill for architecture reviews, readiness assessments, trade-off analysis, migration programs, or requests to align an AWS design to AWS frameworks.

## Well-Architected review

Review Operational Excellence, Security, Reliability, Performance Efficiency, Cost Optimization, and Sustainability. For each pillar, state the workload-specific questions asked, evidence available, gap, risk, owner, priority, and recommended action. Include the workload boundary and review date.

## CAF framing

Use Business, People, Governance, Platform, Security, and Operations perspectives for organization and transformation readiness. Map capabilities to workstreams, owners, dependencies, skills, processes, and measurable outcomes. CAF readiness is broader than a technical topology.

## Evidence discipline

Use the current official framework and applicable lenses. Do not claim "Well-Architected" or "CAF compliant" from a static diagram or a few controls. Distinguish review findings from AWS certification, audit, or formal AWS Well-Architected Tool results.

Read [references/framework-routing.md](references/framework-routing.md) when selecting the appropriate framework lens.
