# Course Architecture and Syllabus

Use when converting a course package or Learn path into a schedule for a specific audience and duration.

Start with audience, outcomes, prerequisites, delivery mode, class size, environment, and fixed constraints. Sequence concepts before practice, practice before assessment, and assessment before transfer. Give every block a purpose, owner, duration, modality, learner action, and fallback. Mark official required content versus optional instructor customization. Include breaks, setup time, questions, accessibility, and buffer; never pretend a deck's slide count equals teaching time.

Provide a short agenda plus a detailed syllabus, timing risks, optional cuts, extension activities, and a rationale for sequencing.
