# Microsoft 365 App Workflows

Use when a lesson spans more than one Microsoft 365 app or teaches an end-to-end work scenario.

Model the user's outcome first, then choose the best starting surface: Copilot Chat, a specific app, Search, an agent, or a human step. Define inputs, context, permissions, transformations, handoffs, review points, and the final artifact. Teach what remains manual. Use safe synthetic files, meeting transcripts, messages, spreadsheets, and agendas. Account for OneDrive save behavior, sharing, sensitivity labels, and the fact that app capabilities may differ by license or rollout.

Return a workflow map, demo sequence, learner practice, verification checklist, and fallbacks for unavailable features.
