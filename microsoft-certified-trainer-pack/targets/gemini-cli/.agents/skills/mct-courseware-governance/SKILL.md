# MCT Courseware Governance

Use when supplied material comes from Microsoft Official Curriculum, Microsoft Learn, the Learning Download Center, a Trainer Preparation Guide, a Change Log, or a Microsoft course package.

## Method

1. Record source filename, course code/version, date, access context, and intended use.
2. Treat the Change Log as the first signal for updates; map affected modules, slides, labs, links, and assessments.
3. Separate official content, learner-facing instructions, instructor customization, and locally authored additions.
4. Preserve links to current Microsoft Learn units and official documentation instead of copying large restricted passages.
5. Flag license, redistribution, account, tenant, and data handling boundaries for the authorized trainer.
6. Produce a source ledger and refresh trigger for future revisions.

## Output

Return a provenance table, permitted-use assumptions, change impact, unresolved licensing questions, and the exact artifacts that need refresh. Never claim that access to a local file proves permission to redistribute it.
