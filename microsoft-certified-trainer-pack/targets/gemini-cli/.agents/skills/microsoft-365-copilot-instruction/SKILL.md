# Microsoft 365 Copilot Instruction

Use when creating or reviewing content for Copilot Chat, Word, PowerPoint, Excel, Teams, Outlook, Copilot Search, agents, or work/web data.

Explain where the learner starts, what context is available, why the response may differ, and how to verify output. Teach prompts as Context, Goal, Source, and Expectations when that framework is applicable. Explain that access follows the user's permissions and that licensing, rollout, app surface, tenant policy, and UI can vary. Separate work-grounded, web-grounded, uploaded, and user-provided context. Include fact-checking, sensitivity, attribution, and human review. Never present generated content as authoritative without verification.

Use current Microsoft documentation for feature claims and record the tenant assumptions behind every demo.
