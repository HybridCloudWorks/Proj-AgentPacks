# Copilot Studio Course Labs

Use when training learners to create or understand Copilot Studio agents, topics, knowledge, tools, MCP connections, agent flows, evaluation, channels, or publishing.

Teach the lifecycle: define purpose and boundaries → configure instructions and knowledge → add tools or flows → test representative and adversarial cases → evaluate groundedness, safety, and task success → obtain approval → publish only when explicitly authorized → monitor and improve. Use synthetic data and least privilege. Include failure cases, ambiguous requests, permission denial, prompt injection, data leakage, escalation, and reset steps. Distinguish designer preview from a published channel and document connector or environment dependencies.
