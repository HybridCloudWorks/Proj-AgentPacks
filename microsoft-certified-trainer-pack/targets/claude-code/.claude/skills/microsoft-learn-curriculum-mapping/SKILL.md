# Microsoft Learn Curriculum Mapping

Use when designing from learn.microsoft.com or reconciling a course package with the current Learn experience.

Create a map with course code/title, module and unit URL, stated objective, prerequisite, learner action, demo or lab, knowledge check, evidence of completion, and instructor customization. Prefer the current Microsoft Learn page as the instructional source of truth while retaining the supplied courseware version and change log as historical context. Identify moved, retired, renamed, or missing units and do not silently substitute content.

End with coverage gaps, timing implications, source citations, and a refresh date. Keep official wording brief and link to the source.
