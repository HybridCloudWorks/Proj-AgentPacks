# Instructor-Led Facilitation

Use for instructor guides, talk tracks, classroom plans, delivery coaching, or sessions with mixed experience.

For each concept, prepare a concise What, Why, How, example, question, and learner action. Use diagnostic questions before prescribing depth. Invite prediction, pair discussion, teach-back, and troubleshooting rather than continuous lecture. Explain why an answer is correct, acknowledge uncertainty, and park questions with an explicit return point. Provide options for remote, in-person, accessibility, and time-shortened delivery. Include recovery moves for demo failure, learner drift, environment failure, and sensitive questions.

Return facilitator cues, transitions, questions, expected misconceptions, inclusion notes, and timing controls.
