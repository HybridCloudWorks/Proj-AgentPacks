# Microsoft Certified Trainer Agent/Skill Pack

A portable, source-traceable agent pack for an authorized Microsoft Certified Trainer who plans, adapts, delivers, evaluates, and maintains Microsoft Official Curriculum and Microsoft Learn-aligned courses. It covers professional instructor-led teaching, PowerPoint courseware, labs and demonstrations, Microsoft 365 Copilot, Copilot Studio, Designer, Office workflows, GitHub course repositories, and Azure handoffs.

The primary trainer agent is fully capable on its own. Specialist agents are optional delegation paths for course architecture, labs and demos, courseware engineering, and Copilot learning review.

This pack is not a claim that the user or an agent holds MCT status, courseware redistribution rights, tenant access, product licenses, or permission to publish changes. Verify those boundaries in the operating environment.
