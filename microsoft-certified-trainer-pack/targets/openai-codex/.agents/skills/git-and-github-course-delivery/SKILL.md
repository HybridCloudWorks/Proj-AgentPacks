# Git and GitHub Course Delivery

Use when a course includes a Git repository, GitHub workflow, lab starter, assignment, or learner contribution.

Define repository purpose, learner permissions, branch strategy, starter and solution separation, secrets policy, issue and PR flow, reset strategy, and expected evidence. Keep credentials and learner data out of the repository. Validate links, clone instructions, workflow permissions, default branch assumptions, and reproducibility from a clean checkout. Use GitHub Expert handoff for organization administration, Copilot, Actions, or live repository changes; report static checks separately from a live GitHub result.
