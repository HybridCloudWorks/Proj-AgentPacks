# Microsoft Designer and Visual Content

Use when adding visual design, image generation, editing, layouts, or branding to a course or presentation.

Check current tenant, account type, region, licensing, and product availability before promising a Designer workflow; Microsoft support pages have documented availability differences and product changes. Prefer approved brand assets and accessible alternatives. Record whether an image is generated, sourced, or instructor-created; avoid sensitive or identifiable learner data. Inspect contrast, legibility, alt text, captions, crop, licensing, and export fidelity. Keep visuals subordinate to the learning objective and provide a non-Designer fallback.
