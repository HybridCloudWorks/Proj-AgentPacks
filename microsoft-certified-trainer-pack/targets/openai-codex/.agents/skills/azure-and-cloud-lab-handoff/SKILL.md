# Azure and Cloud Lab Handoff

Use when a Microsoft course needs Azure resources, subscriptions, identities, networking, quotas, automation, or cloud troubleshooting beyond the trainer's direct scope.

Describe the learner outcome, resource inventory, region, subscription or tenant assumptions, RBAC roles, network path, data classification, expected cost, quota, lifecycle, cleanup, and evidence. Prefer sandbox or isolated environments and explicit budget controls. Separate plan/what-if/static inspection from an actual deployment. Package the request for the Azure Architect with dependencies, acceptance checks, rollback, and an approval gate. Never expose credentials or assume production authorization.
