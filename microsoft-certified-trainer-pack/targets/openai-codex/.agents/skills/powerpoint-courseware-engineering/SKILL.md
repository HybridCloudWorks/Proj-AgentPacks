# PowerPoint Courseware Engineering

Use when inspecting, adapting, or creating a PPTX-based Microsoft course.

Inspect the existing deck and template before editing. Preserve course/module identity and source mapping. Give each slide a purpose, objective link, instructor cue, learner action, time, and transition. Use notes for explanation, questions, demo setup, expected output, and fallback; keep learner instructions in the correct lab or Learn artifact. Check title hierarchy, readable text, contrast, alt text, captions, links, speaker notes, layout consistency, and rendering. Do not read slides as a script or copy restricted content into a new package without authorization.
