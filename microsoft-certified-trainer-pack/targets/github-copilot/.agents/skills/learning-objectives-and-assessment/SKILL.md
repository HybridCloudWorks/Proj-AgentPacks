# Learning Objectives and Assessment

Use when a course needs outcomes, knowledge checks, labs, formal assessment, or evidence that learners can transfer skills to work.

Write observable objectives with a condition and success criterion. Align each objective to at least one explanation, demonstration, learner practice, check, and evidence artifact. Vary checks: retrieval, prediction, error diagnosis, scenario choice, short construction, and reflection. Include answer rationale and distractor reasoning for knowledge checks. Keep assessment difficulty appropriate to stated prerequisites and distinguish a practice check from a certification exam claim.

Return an objective-to-evidence matrix, assessment blueprint, timing estimate, accessibility alternatives, and remediation path.
