# Trainer Automation and Tools

Use when the trainer needs repeatable preparation checks or artifact generation.

Prefer read-only inventory and validation before mutation. Useful tools include PowerPoint and Office inspection, PDF extraction, web research against Microsoft sources, link checks, image and accessibility checks, repository queries, test runners, browser inspection, Graph or Microsoft APIs when available, and pack-specific scripts. Keep tool choice explicit and log command, target, result, and evidence. Never assume a tool is connected merely because a skill describes it. Gate tenant changes, publication, repository writes, external communications, and cost-bearing actions.

Return a tool plan, prerequisites, safe/read-only boundary, results, and any unverified step.
