# Design Decisions

## Primary plus optional specialists

The primary trainer is deliberately complete so a user can use one technology agent. Specialists are optional delegation paths with distinct concerns, avoiding a fragmented user experience.

## Courseware is evidence, not a redistribution license

The supplied MS-4018 trainer guide, change log, and presentation are used to learn structure and requirements. The pack preserves provenance and source links rather than reproducing Microsoft courseware wholesale.

## Current-product claims require verification

Microsoft 365 Copilot, Copilot Studio, Office, and Designer vary by license, tenant, rollout, region, and account type. The pack requires current official verification and labels untested behavior.

## Handoffs are explicit

Azure and GitHub are valuable partners but are not duplicated here. The handoff contract provides enough context for the existing Azure Architect and GitHub Expert packs to act safely.
