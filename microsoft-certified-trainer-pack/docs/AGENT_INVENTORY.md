# Agent Inventory

| Agent | Role | Direct use |
|---|---|---|
| `microsoft-certified-trainer` | Full primary trainer and course-production orchestrator | Yes |
| `microsoft-course-architect` | Objectives, curriculum map, syllabus, assessment | Optional |
| `microsoft-lab-demo-engineer` | Labs, demos, preflight, reset, fallback | Optional |
| `microsoft-courseware-engineer` | PPTX, notes, accessibility, artifact quality | Optional |
| `microsoft-copilot-learning-reviewer` | Copilot, Copilot Studio, Designer, privacy, current feature review | Optional |

The primary agent carries the complete capability surface. Specialists reduce context switching or support focused delegation; they are not required for completeness.
