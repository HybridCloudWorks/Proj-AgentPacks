# Training Content Maintenance

Use when refreshing a course, reviewing a Change Log, or checking whether demos and labs still match Microsoft products.

Maintain a versioned inventory of sources, links, slides, notes, labs, sample data, prompts, screenshots, and assessments. Run a change review that classifies each difference as cosmetic, instructional, functional, licensing, security, or breaking. Update the source map, objective coverage, agenda, demos, lab steps, knowledge checks, accessibility notes, and fallback. Mark unverified features and preview behavior. Record owner, date, evidence, and next review trigger.
