# Trainer Preparation and Rehearsal

Use before delivering a course or when a new courseware release arrives.

Review all current Learn topics, supplied decks, talking points, change log, additional reading, knowledge checks, labs, sample files, and prerequisites. Build a preparation checklist that covers tenant and license readiness, account permissions, sample-data safety, links, downloads, room or meeting setup, accessibility, and escalation contacts. Perform each lab and demo in a clean or resettable environment. Record actual timing, friction, failure modes, and fallback explanations. Rehearse transitions and learner questions; do not read slide bullets verbatim.

Return a signed-off preflight, rehearsal evidence, open risks, and go/no-go recommendation.
