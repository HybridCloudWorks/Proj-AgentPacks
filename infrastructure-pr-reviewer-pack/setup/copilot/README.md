# GitHub Copilot Installation Collateral

The generated Copilot target contains the native Agent, all Skills, and the path-specific instruction file. This setup directory contains files that require deliberate merge or repository-policy decisions.

- Merge `copilot-instructions-snippet.md` into `.github/copilot-instructions.md`.
- Merge or adopt `infrastructure-pull-request-template.md` in the repository's PR template location.
- Use `repository-enforcement-checklist.md` to configure non-AI enforcement.
- Read the `github-copilot-setup.md` reference in the primary Skill for current installation and limitation guidance.
